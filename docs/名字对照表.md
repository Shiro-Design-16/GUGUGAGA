# 咕咕嘎嘎语 · 名字对照表

> 源码里的位只有两种：0 与 1；默认用 `咕`/`嘎` 写，也可以写 `グ`/`ガ`（日语，兼容 `ぐ`/`が`）或 `GU`/`GA`（英语，大小写不敏感）。三方言逐位置等价，可混写；本表一律用中文方言。
> 本表把每个示例里的位串翻译成人话，并对应到 Java 概念，方便人类阅读这些程序。
> 文件名已改成纯咕嘎（`examples/咕嘎咕嘎.咕咕` 等），因为文件名会出现在屏幕和 `ls` 里。目录名（`src/`、`tests/` 等）仍用 ASCII：那是宿主工具链的骨架，改它会打断 Node 的模块解析。

## 0. 通用速查

### 0.1 语法糖

| 字串 | 含义 | Java 概念 |
| --- | --- | --- |
| `咕咕！ <名字>` | 定义类 | `class` |
| `咕咕！ <子类>：<父类>？` | 继承 | `extends` |
| `咕咕嘎！ <方法名> [：<参数>]*` | 定义方法；方法名与类名相同即构造器 | 方法 / 构造器 |
| `咕咕嘎嘎！ <名字>` | 程序入口（静态上下文，没有「自己」） | `public static void main(String[])` |
| `咕嘎嘎！ <类名>？ [：<实参>]*` | 新建实例 | `new` |
| `咕咕！？ <名字>：<表达式>` | 类体里 = 声明字段；方法体里 = 赋值 / 新建局部 | 字段声明 / `x = expr` |
| `咕咕！？ <原子> <成员名>：<表达式>` | 写对象字段 | `obj.field = expr` |
| `咕嘎！？ <表达式>` | 求值并丢弃结果（用于副作用） | `expr;` |
| `咕：<表达式>` | 输出（写裸位流） | `System.out.write(...)` |
| `嘎嘎：<表达式>` | 返回 | `return` |
| `嘎嘎嘎：<条件>` + 缩进块 | 若 | `if` |
| `嘎嘎嘎嘎` + 缩进块 | 否则（必须紧跟同层「若」） | `else` |
| `嘎嘎嘎嘎嘎：<条件>` + 缩进块 | 循环 | `while` |
| `嘎嘎嘎嘎嘎嘎` | 自己 | `this` |
| `嘎嘎嘎嘎嘎嘎嘎` | 从 stdin 读 1 字节 → 整数 0–255；EOF → 空 | `System.in.read()` |
| `<名字>？` | 读取该名字 | 变量/字段/参数求值 |
| `<接收者> <方法名>！ [：<实参>]*` | 方法调用（实参个数 = `：` 槽个数） | `recv.m(args)` |
| `嘎嘎嘎？<位串>` | 整数（二进制写法，`咕`=0 `嘎`=1） | `int` 字面量 |
| `嘎嘎嘎嘎？<位串>` | 位串字面量（逐位照抄，按字节约定即 UTF-8 片段） | `byte[]` 常量 |
| `嘎嘎？` / `嘎嘎咕？` / `嘎咕？` | 真 / 假 / 空 | `true` / `false` / `null` |

### 0.2 运算符（前缀式，没有括号，嵌套实参要先绑局部变量）

| 字串 | 含义 | Java 概念 |
| --- | --- | --- |
| `咕？` | 加（整数相加；两个位串 = 拼接） | `+` |
| `咕咕？` `咕嘎？` `咕咕咕？` `咕咕嘎？` | 减 乘 除（向零截断） 取余 | `-` `*` `/` `%` |
| `咕嘎咕？` `咕嘎嘎？` `咕嘎嘎咕？` | 相等 小于 大于 | `==` `<` `>` |
| `咕嘎咕咕？` `咕嘎咕嘎？` `咕咕咕咕？` | 与 或 非（两侧都会求值，不短路） | `&&` `\|\|` `!` |
| `咕咕嘎咕？` | 负 | 一元 `-` |

### 0.3 输出编码（SPEC §6）

| 值类型 | 输出 | Java 概念 |
| --- | --- | --- |
| 整数 | 定长 64 位补码，高位在前；超出取低 64 位 | `long` |
| 位串 | 原样逐位照抄 | `byte[]` |
| 布尔 | 8 位：假 = 8 个 `咕`，真 = 8 个 `嘎` | 1 字节 |
| 空 / 对象 | 报 E4006，不能输出 | — |

stdout 是**连续裸位流**：没有分隔符、没有换行、没有结尾换行。字符串统一用位串按 UTF-8（每字节 8 位、高位在前）表示。

## 1. `examples/咕嘎咕嘎.咕咕`

用途：输出 UTF-8 字符「嗨」的三个字节，演示「位串字面量 + 拼接」。

| 位串 | 中文含义 | Java 概念 |
| --- | --- | --- |
| `嘎咕嘎嘎嘎咕` | 入口名（随便起的，叫什么都行） | `main` 方法名 |
| `嘎嘎嘎嘎？嘎嘎嘎咕咕嘎咕` | 位串 `11100101` = 0xE5（「嗨」UTF-8 第 1 字节） | `(byte)0xE5` |
| `嘎嘎嘎嘎？嘎咕咕嘎咕嘎嘎嘎` | 位串 `10010111` = 0x97（第 2 字节） | `(byte)0x97` |
| `嘎嘎嘎嘎？嘎咕嘎咕嘎咕咕咕` | 位串 `10101000` = 0xA8（第 3 字节） | `(byte)0xA8` |
| `咕？` | 位串拼接（两次） | 字符串/数组串接 |
| `咕：` | 输出 24 位裸位流 | `System.out.write(new byte[]{...})` |

期望输出：`11100101 10010111 10101000`（24 位，中间无空格、无换行）= `E5 97 A8` = 「嗨」。

## 3. `examples/嘎嘎咕咕.咕咕`

用途：父类 + 子类继承、构造器带参数、子类覆写同名方法；用父类/子类两个接收者各调一次，体现动态派发。

| 位串 | 中文含义 | Java 概念 |
| --- | --- | --- |
| `嘎嘎咕嘎嘎` | 父类 | `class Base` |
| `嘎嘎咕嘎嘎咕` | 子类 | `class Sub extends Base` |
| `嘎咕咕嘎咕` | 标签字段（父类声明，子类继承） | `byte[] tag` |
| `嘎咕咕咕嘎` | 构造器参数 | `byte[] tag` |
| `嘎嘎咕嘎嘎：嘎咕咕咕嘎` | 父类构造器（1 参） | `Base(byte[] tag)` |
| `嘎嘎咕嘎嘎咕：嘎咕咕咕嘎` | 子类构造器（1 参） | `Sub(byte[] tag)` |
| `嘎咕嘎嘎咕` | 方法，子类里同名覆写 | `byte[] speak()` |
| `嘎咕嘎嘎嘎咕` | 入口 | `main` |
| `嘎嘎咕嘎咕咕` / `嘎嘎咕嘎咕嘎` | 父类实例 / 子类实例 | `Base p` / `Sub c` |
| `嘎嘎嘎嘎嘎嘎` | 自己（读自己的字段） | `this` |
| `嘎嘎嘎嘎？嘎嘎嘎嘎咕咕咕咕` | 0xF0 | `(byte)0xF0` |
| `嘎嘎嘎嘎？嘎嘎嘎嘎嘎嘎嘎嘎` | 0xFF | `(byte)0xFF` |
| `咕？` | 两个位串拼接 | 数组串接 |

期望输出：父类接收者 → 8 位 `11110000`（0xF0）；子类接收者 → 16 位 `11111111 11111111`（0xFF 0xFF）。同一个方法名、两个不同结果，即动态派发。

## 4. `examples/咕嘎嘎咕.咕咕`

用途：从 stdin 读两个字节，做加、减，输出两个 64 位整数。

| 位串 | 中文含义 | Java 概念 |
| --- | --- | --- |
| `嘎咕嘎嘎嘎咕` | 入口 | `main` |
| `嘎嘎咕嘎咕咕` / `嘎嘎咕嘎咕嘎` | 读到的两个字节 | `int a, b` |
| `嘎嘎嘎嘎嘎嘎嘎` | 读入 1 字节 → 0–255 | `System.in.read()` |
| `咕？` / `咕咕？` | 加 / 减 | `a + b` / `a - b` |

**stdin 该喂什么**：程序连续读 2 个字节，所以必须喂至少 2 字节。例如：

```sh
printf '35' | node bin/gg.ts examples/咕嘎嘎咕.咕咕   # 读 0x33=51、0x35=53
printf '\003\005' | node bin/gg.ts examples/咕嘎嘎咕.咕咕   # 读 3、5
```

- `printf '35'`：加 = 51+53 = **104**，减 = 51−53 = **−2**，输出 64+64 = 128 位（前 64 位 104，后 64 位 −2 的补码）。
- `printf '\003\005'`：加 = **8**，减 = **−2**。
- 只喂 1 个字节（或空 stdin）：第二次读入得到「空」，随后 `加/减` 遇到非整数 → 运行期错误 E4004。

## 5. `examples/嘎咕嘎咕.咕咕`

用途：布尔运算（小于、与、非）与「若 / 否则」两条路径各输出一段可区分的位串。

| 位串 | 中文含义 | Java 概念 |
| --- | --- | --- |
| `嘎咕嘎嘎嘎咕` | 入口 | `main` |
| `嘎嘎咕嘎咕咕` / `嘎嘎咕嘎咕嘎` | 两个整数（5 和 7） | `int a = 5, b = 7` |
| `嘎嘎嘎？嘎嘎咕` / `嘎嘎嘎？嘎嘎嘎` | 整数 5 / 7 | `5` / `7` |
| `咕嘎嘎？` | 小于 | `a < b` |
| `咕嘎咕咕？` | 与 | `&&` |
| `咕咕咕咕？` | 非 | `!` |
| `嘎嘎嘎：` | 若 | `if` |
| `嘎嘎嘎嘎` | 否则 | `else` |
| `嘎嘎嘎嘎？嘎咕嘎咕嘎咕嘎咕` | 0xAA（「真」分支的标签） | `(byte)0xAA` |
| `嘎嘎嘎嘎？嘎嘎嘎嘎嘎嘎嘎嘎` | 0xFF（「假」分支的标签） | `(byte)0xFF` |

期望输出：第一条「若」（`a < b` 为真）走**真**分支 → `10101010`（0xAA）；第二条「若」（`非 (a < b)` 为假）走**否则**分支 → `11111111`（0xFF）。共 16 位，两条路径都被执行到。

## 5.5 两个方言样例（`examples/ガググガグ.ググ` / `examples/gugugaga.gu`）

这两个样例是 `SPEC.md` §11 那个最小程序（类 + 字段 + 方法 + 新建 + 调用）的方言写法——归一化后位流逐位相同，都是 64 位整数 0（字段初始化成 `嘎嘎嘎？咕`），解出来是 `0`。输出字形跟文件后缀走：中文样例 64 个 `咕`/`嘎`（192 字节）、日语样例 64 个 `グ`/`ガ`（192 字节）、英语样例 128 个 `GU`/`GA` 字母（128 字节）。下表是同一段代码在三种方言里的拼写：

| 概念 | 中文 | 日语 | 英语 |
| --- | --- | --- | --- |
| 入口头 | `咕咕嘎嘎！` | `ググガガ！` | `GUGUGAGA!` |
| 打印 | `咕：` | `グ：` | `GU:` |
| 整数字面量前缀 | `嘎嘎嘎？` | `ガガガ？` | `GAGAGA?` |
| 位 1 | `嘎` | `ガ` | `GA` |
| 缩进 | 4 个半角空格 | 4 个全角空格 U+3000 | 4 个半角空格 |

差别只在拼写与缩进字符，语法结构、记号种类、语义完全一致：名字可以混排（`ガグGA` 是合法名字），英文位名必须成对（落单 `g` 是 E1001）。文件后缀也只是「是不是一个程序」的判据：`.咕咕` / `.ググ` / `.gu` / `.gugugaga` 都认。

## 6. 跑起来

```sh
node bin/gg.ts examples/咕嘎咕嘎.咕咕              # 退出码 0；stdout 是 24 位裸位流
node bin/gg.ts examples/咕咕嘎嘎.咕咕 | wc -m         # 320 个字符（咕/嘎），没有换行；`wc -c` 会得 960，因为每个字占 3 字节
node --test "tests/**/*.test.ts"                     # 示例端到端 + 字符集校验
```

注意：stdout **没有换行**，别直接 `cat`（会把提示符顶到下一行、看起来像卡住）。要看结果请重定向，或用 `| wc -m` 数字符、`| head -c 60` 截字节。
