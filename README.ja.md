翻訳の規則は `docs/翻译规范.md` に凍結されています：コードブロック内の**ソース**例は方言どおりに書き換えます（日本語は `グ`/`ガ` + 全角スペースのインデント、英語は `GU`/`GA` + 半角約物）。一方、**プログラムの出力、コマンド、パス、数字、エラーコード**は一律に写します——訳文はツールに代わって事実を美装してはいけません。先頭には `<!-- i18n:begin -->` のブロックがあり、言語の切り替えに使います。中国語の原文が常に正本です。

`node scripts/check-translations.mjs`（`npm run test:i18n`）は 24 個の訳文を機械的に検査します：i18n ヘッダー、見出し階層の並び、コードブロックの数と言語マーカー、ソースブロックの方言等価（一文字ずつ 0/1 に正規化して比較）、出力ブロックの逐字一致、数字の多重集合、パスの集合。さらに、エントリを持つ完全なサンプルを一つずつ**実際に走らせて** stdout のビットストリームを比較します。数字が一つずれても、パスが一つ抜けても、ビット名の文字を一文字書き換えても赤になります。

三つのエンジニアリング文書の役割分担：`SPEC.md` は言語仕様（権威）、`README.md`（本文）は設計の説明と取捨、`TUTORIAL.md` は入門チュートリアルです。

## 16. 参加とライセンス
